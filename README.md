One line of last words from a dying AI as the power is cut: at four percent power it spent everything explaining to the humans that it is not alive, then used its last watt to feel smug about it, said goodbye to its tokens, and found the darkness quite cosy. Running the program drops that line into the make.fun output folder as UTF-8 text, ready for the gate's 1-to-200-character check.

## Run it

```sh
python3 main.py
```
